# Slide 3: Cara Mengakses Studio Anda
**Judul:** Masuk ke dalam Editor
1.  Buka tautan AI Studio Build yang disediakan dalam dokumen serah terima Anda.
2.  Masuk (Login) menggunakan Akun Google Anda.
3.  Anda akan melihat dua panel utama:
    *   **Panel Kiri:** Antarmuka Chat (tempat Anda mengobrol dengan AI).
    *   **Panel Kanan:** Live Preview & Code Editor (tempat Anda melihat perubahannya secara langsung).

# Slide 4: Menggunakan Antarmuka Chat
**Judul:** Cara Berbicara dengan Developer AI Anda
*   Gunakan kotak chat di kiri bawah untuk meminta perubahan.
*   **Fitur Edit di Preview:** Anda bisa menggunakan tool edit (ikon kursor/pensil) yang ada di pojok layar *Live Preview* untuk menyeleksi secara spesifik elemen mana yang ingin diubah, sehingga jauh lebih mudah memberikan instruksi yang akurat ke AI.
*   **Spesifik:** Sebutkan secara pasti apa yang ingin Anda ubah dan di mana posisinya.
*   **Contoh 1 (Buruk):** "Buat ini lebih menarik."
*   **Contoh 2 (Baik):** "Ubah warna latar belakang bagian hero (paling atas) menjadi biru malam yang lembut."
*   **Mengunggah Aset:** Anda bisa menarik dan melepas (drag and drop) gambar ke dalam chat dan meminta AI untuk menggunakannya di website.

# Slide 8: Praktik Terbaik Memberikan Perintah (Prompting)
**Judul:** Mendapatkan Hasil Terbaik
1.  **Ulangi dan Perbaiki:** Jika AI tidak membuat dengan 100% tepat pada percobaan pertama, cukup perbaiki arahannya. ("Buat tombol itu sedikit lebih besar dan teksnya ditebalkan.")
2.  **Satu per Satu:** Untuk pembaruan yang kompleks, mintalah perubahan langkah demi langkah daripada meminta sekaligus dalam satu paragraf panjang.
3.  **Konfirmasi Detail:** Jika AI meminta Anda untuk mengonfirmasi pilihan teknis, Anda bisa menjawab "Pilih opsi yang terbaik untuk website e-commerce."

# Slide 9: Memperbarui tenunstore.com (via GitHub & Hostinger)
**Judul:** Meluncurkan Pembaruan ke Website Live Anda
*   Repositori GitHub Anda saat ini sudah terhubung langsung ke **Hostinger**.
*   Ini berarti, Anda tetap menggunakan repositori ini untuk semua pembaruan di masa mendatang.
*   **Langkah Pembaruan:**
    1. Lakukan perubahan desain atau fitur di AI Studio.
    2. Klik ikon **Share** / **Settings** (Pengaturan), lalu pilih **Export to GitHub**.
    3. AI Studio akan memperbarui repositori GitHub utama Anda.
    4. **Hostinger** akan mendeteksi perubahan tersebut secara otomatis dan langsung menerapkan pembaruan ke website **tenunstore.com** Anda.
*   Anda tidak perlu mengatur ulang server atau masuk ke cPanel, semuanya berjalan otomatis!
